# Srujan S — liquid-glass portfolio

This is the complete editable source for the approved neural-brain design.
It is deployed as a static site: Vercel serves this repository root, with
`index.html` as the entry point, and redeploys automatically on every push.

## Open it locally

Open `index.html` in a browser. No install or build is required.
For browser features that prefer localhost (such as copying the contact email),
run this command from the repository root and open http://127.0.0.1:4173:

    python3 -m http.server 4173 --bind 127.0.0.1

The artwork and project previews are bundled. The optional Google Font and
external demo, social, and résumé links use the internet.

## Edit it

- `index.html`: complete ready-to-run page (generated by `scripts/build.py`).
- `style.css`: responsive layout, glass surfaces, typography, and motion.
- `app.js`: project filters, previews, navigation, and email copy.
- `assets/`: neural-brain artwork, project screenshots, diagrams, and favicon.
- `content.json`: projects, skills, and experience data by discipline.
- `scripts/build.py`: editable HTML template and page generator, including the bio and contact details.
- `scripts/make-diagrams.py`: regenerates the SVG project diagrams.
- `scripts/check.py`: checks links, assets, and page structure.
- `scripts/extract-content.py`: optional original import utility; expects a saved original portfolio at `/tmp/srujan-original.html`. Normal editing does not require this step.

After editing the template or content data, run these from the repository root:

    python3 scripts/build.py
    python3 scripts/check.py

Building regenerates `index.html`, so keep lasting markup edits in the template.
The project needs no API keys or build configuration — pushing to GitHub triggers
the Vercel deployment.
